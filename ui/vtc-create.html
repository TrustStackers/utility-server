🏛️ Create a Verified Trust Community (VTC)

A VTC is itself an identity (identities.role='vtc', subject_kind NULL — it's a governance construct, not a subject). It is governed by a set of founding admins under an M-of-N co-signing threshold recorded in governance. Founding admins become memberships rows (role='founding_admin', status='active'), and a status_lists row (purpose='revocation') is minted alongside it, with reserved decoy indices 0–3 pre-flipped so a new community's first real member isn't identifiable by slot position.
